    Switching template keeps every post and page. Colours and fonts the new template does not offer are dropped. Preview renders your real content with a template without adopting it, and shows drafts too.

      Your own templates

      Uploaded to this site's own storage. No other site can see or use them, and publishing never touches them. Pick the folder that holds template.json; every upload becomes a new version, so the one that was working is still there to go back to.

        Static pages

        Complete HTML files, published exactly as given, for pages the editor cannot express. They carry none of the site's chrome and are not searchable — use a static page when you want to own all the markup, and a normal page when you want the template around it.
